# Donald Sadoway Chemistry — GitHub Pages website

A responsive, 3Blue1Brown-inspired visual system for a chemistry coaching website targeting CBSE, NEET and JEE aspirants.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design, layout, animations and visual system
- `script.js` — mobile menu, reveal animations, counters and Web3Forms AJAX submission

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload the three website files (`index.html`, `style.css`, `script.js`).
3. Commit to `main`.
4. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.
5. Open the generated `.github.io` URL.
